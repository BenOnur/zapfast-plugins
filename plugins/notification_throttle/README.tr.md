# Bildirim Aralığı

[English](README.md) | [Türkçe](README.tr.md)

Aynı kişi ve bağlı hesap için ilk uygun bildirimi gösterir, sonraki 30 saniyedekileri bastırır. Aralık dolduktan sonraki ilk mesaj yeni pencereyi başlatır; sonradan gecikmiş bildirim göndermez. Normal sessiz/kitli sohbet ve işletim sistemi bildirim kuralları geçerlidir.

- Host: API v1 veya daha yeni; fork v0.19.1 destekler.
- `interval_seconds`: varsayılan 30 saniye; Plugins ekranından değiştirilebilir.
