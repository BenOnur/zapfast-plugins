# Notification Throttle

[English](README.md) | [Türkçe](README.tr.md)

Shows the first eligible notification for each sender and linked account, then suppresses further ones for 30 seconds by default. The first message after the interval starts a new window; no delayed notification is scheduled. Normal muted/locked chat and operating-system notification rules still apply.

- Host: API v1 or newer; fork v0.19.1 is supported.
- `interval_seconds`: 30 seconds by default; configurable in Plugins.
